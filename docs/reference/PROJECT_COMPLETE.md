## 使用方式

### 安装
```bash
cd rvm-rs
cargo build --release
```

### 基础使用
```bash
# 解析 RVM 文件
cargo run --release -- model.rvm

# 导出为 OBJ
cargo run --release -- model.rvm --export-obj output.obj

# 导出为 GLTF
cargo run --release -- model.rvm --export-gltf output.gltf
```

### 运行测试
```bash
cargo test
```
